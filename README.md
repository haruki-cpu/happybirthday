# 🎂 きみへ — 誕生日ガチャサイト

## フォルダ構成

```
birthday/
├── index.html       ← サイト本体
├── photos.json      ← 日付と写真ファイル名の対応表
├── photos/          ← 写真を入れるフォルダ
│   ├── IMG_3042.jpg
│   └── ...
└── README.md        ← この説明書
```

---

## 写真の追加方法

### 1. 写真をアップロード

GitHubの `photos/` フォルダに写真ファイルをアップロードします。
ファイル名はそのままでOKです（例: `IMG_3042.jpg`）。

### 2. photos.json を編集

`photos.json` に1行追記します。

```json
{
  "2025-05-01": "IMG_3042.jpg",
  "2025-05-10": "photo_spring.jpg",
  "2025-06-01": "DSC_0291.jpg"
}
```

**ルール**
- キー（左側）は `YYYY-MM-DD` 形式の日付
- 値（右側）は `photos/` フォルダに入れたファイル名
- 最後の項目以外はカンマ `,` を付ける

---

## GitHub Pages 公開手順

1. GitHubで新しいリポジトリを作成（例: `birthday`）
2. このフォルダの中身をすべてアップロード
3. リポジトリの **Settings → Pages**
4. Source を `Deploy from a branch` → `main` → `/ (root)` に設定
5. **Save** を押す
6. 数分後に `https://あなたのID.github.io/birthday` で公開される ✅

## 機能

- 🎂 **カウントダウン** — 6月30日まで秒刻みで表示
- 🎰 **1日1回ガチャ** — カプセルアニメーション付き
- 📷 **ポラロイド写真** — 引いた日の思い出が出てくる
- 📚 **アルバム** — 引いた写真だけ解放、まだの写真は🔒
- 🎉 **紙吹雪** — 写真が出るたびに降ってくる
