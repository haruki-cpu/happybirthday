# 🎀 夏希との思い出カウントダウンガチャ

## フォルダ構成

```
(リポジトリのルート)/
├── index.html       ← サイト本体
├── photos.json      ← 写真ファイル名のリスト
├── photos/          ← 写真を入れるフォルダ
│   ├── IMG_3042.jpg
│   └── ...
└── README.md
```

---

## 写真の追加方法

### 1. 写真を `photos/` フォルダにアップロード
ファイル名はそのままでOKです。

### 2. `photos.json` を編集して追記する

```json
[
  "IMG_3042.jpg",
  "photo_spring.jpg",
  "DSC_0291.jpg"
]
```

- ファイル名を `"` で囲んでカンマ区切りで並べるだけ
- 最後の項目だけカンマなし

---

## GitHub Pages 公開手順

1. GitHubで新しいリポジトリを作成（例: `natsuki`）
2. このフォルダの中身をすべてアップロード
3. Settings → Pages → Source: `Deploy from a branch` → `main` / `root` → Save
4. 数分後に `https://あなたのID.github.io/natsuki` で公開 ✅

---

## 管理者パネルの開き方

サイト下部のフッター（「made with love for 夏希 💕」）を **5回タップ** すると管理者パネルが開きます。

### できること
| 操作 | 説明 |
|------|------|
| 今日のガチャをリセット | もう一度ガチャを引けるようにする |
| 全履歴をリセット | アルバムを全部🔒に戻す |
| 全写真を解放 | 誕生日に全部見せるときなどに使う |

---

## スマホでの使い方

Safari → 共有ボタン → **「ホーム画面に追加」** でアプリのように使えます。
同じブラウザで開き続ければ記録はずっと保存されます。
