# 🎀 夏希との思い出カウントダウンガチャ

夏希へのサプライズ誕生日サイト。毎日ガチャを引いて思い出の写真を開封できる、GitHub Pages で動く静的サイトです。

---

## ファイル構成

```
(リポジトリのルート)/
├── index.html        ← メイン画面（ガチャ・アルバム・プレゼント）
├── game.html         ← ミニゲーム（ハートフラッピー）
├── photos.json       ← 写真ファイル名のリスト
├── photos/           ← 写真ファイルを入れるフォルダ
│   ├── IMG_3042.jpg
│   └── ...
└── README.md
```

---

## GitHub Pages 公開手順

1. GitHub で新しいリポジトリを作成（例: `happybirthday`）
2. 上記ファイルをすべてアップロード（`photos/` フォルダごと）
3. リポジトリの **Settings → Pages → Source: `main` ブランチ → Save**
4. 数分後に `https://あなたのID.github.io/happybirthday` で公開

---

## スマホでの使い方（夏希向け）

Safari（iPhone）→ 共有ボタン → **「ホーム画面に追加」** するとアプリのように使えます。
同じブラウザで開き続ければガチャの履歴・アルバムの解放状況がずっと保存されます。

> ⚠️ **ブラウザのデータを削除すると記録が消えます。** 同じスマホ・同じブラウザで使い続けてください。

## 機能一覧

### 🎰 ガチャ

- 1日1回、カプセルアニメーション付きで写真を1枚開封できる
- 毎日自動で1回分チャージされる（複数日分もたまる）
- 引いた写真はポラロイド風に表示される
- 全写真を引き終わるとリセットしてランダムに再配布

### ⏱ カウントダウン

- 6月30日（誕生日）まで日・時間・分・秒でリアルタイムカウント
- 当日はお誕生日オーバーレイが表示される

### 💬 ひとことメッセージ

- 日付ごとに設定したメッセージが画面上部に表示される
- `index.html` の `LOVE_MESSAGES` 配列を編集して変更

### 📷 思い出コレクション（アルバム）

- ガチャで引いた写真だけグリッドに解放される（まだの写真は 🔒）
- 解放枚数のプログレスバーを表示
- サムネイルをタップするとライトボックスで大きく表示
- ◀ ▶ で解放済み写真を順番に閲覧可能

### 💬 コメント機能

- ライトボックスの入力欄に「ひとことメモ」を入力して保存できる
- 入力したコメントはコレクションのサムネイル下・ポラロイド下にも表示
- スマホのブラウザに自動保存される

### 📥 チェキ保存（ダウンロード）

- ポラロイド風（白背景・写真・💕・コメント）の画像として端末に保存できる
- ガチャ直後のボタンとライトボックス内のボタン、両方から保存可能

### 🎁 プレゼントガチャ

- 指定した日付にガチャを引くと、写真の後にプレゼントボックスが出現
- タップで開封する演出付き（爆発・紙吹雪・背景パーティクル）
- 画像付きプレゼントも設定可能
- 開封したプレゼントは「プレゼントボックス」セクションにたまって、いつでも見返せる

### 🎮 ミニゲーム（game.html）

- メイン画面のバナーからアクセス
- ハートが主人公のフラッピーバード風ゲーム
- リボン柄の障害物をよけてスコアを稼ぐ
- 50個突破でゲームクリア → プレゼントボックス演出（メイン画面のプレゼント欄にも追加される）

## カスタマイズ方法

### 写真の追加

**1. 写真を `photos/` フォルダにアップロード**（ファイル名そのままでOK）

**2. `photos.json` にファイル名を追記**

```json
[
  "IMG_3042.jpg",
  "photo_spring.jpg",
  "DSC_0291.jpg"
]
```

- 配列に `"ファイル名"` をカンマ区切りで追加するだけ
- 最後の項目だけカンマなし
- 写真はこの順番で「何枚目」として管理される

> **Python スクリプト版**: `generate_photos_json.py`（別途提供）を実行すると、フォルダ内の画像を自動でスキャンして `photos.json` を生成できます。

---

### プレゼントの設定（index.html）

`index.html` の上部にある `PRESENT_SCHEDULE` 配列を直接編集します。

```javascript
const PRESENT_SCHEDULE = [
  {
    date:    "2025-06-20",           // ← この日にガチャを引くと出る（YYYY-MM-DD形式）
    title:   "半年記念日プレゼント 🎀", // ← プレゼントのタイトル
    message: "付き合って半年おめでとう！\nこれからもよろしくね 💕", // ← メッセージ（\nで改行）
    image:   ""                      // ← 画像ありの場合は "photos/ファイル名.jpg"、なしは ""
  },
  {
    date:    "2025-06-30",
    title:   "お誕生日プレゼント 🎂",
    message: "夏希、20歳のお誕生日おめでとう！\n大好きだよ 💕",
    image:   ""
  },
  // ↑ ここに追加していく（最大件数の制限なし）
];
```

- `date` は `"YYYY-MM-DD"` 形式で指定
- `image` に `photos/` フォルダの画像ファイル名を入れると、ポラロイド風で画像も表示される

---

### ゲームクリアプレゼントの設定（game.html）

`game.html` の上部にある `GAME_PRESENT` を編集します。

```javascript
const GAME_PRESENT = {
  date:    'game-clear',              // 固定（日付関係なくクリアしたら出る）
  title:   'ゲームクリアプレゼント 🎮',
  message: '50個突破すごい！！\n夏希のことが大好きだよ 💕',
  image:   ''                         // 画像ありの場合はファイル名を入れる
};
```

ゲームのクリア条件（障害物の数）は `GOAL` で変更できます：

```javascript
const GOAL = 50; // ← 数字を変えるとゴールが変わる
```

---

### 日付ごとのひとことメッセージ（index.html）

`index.html` の `LOVE_MESSAGES` 配列を編集します。

```javascript
const LOVE_MESSAGES = [
  { date: '6/1',  msg: '今日もお仕事お疲れ様 💕' },
  { date: '6/15', msg: '準備できた？もうすぐやぞ！✨' },
  { date: '6/30', msg: '夏希お誕生日おめでとう！💕' },
  // 追加したい日付を足していく
];
const LOVE_MSG_DEFAULT = '今日も好きだよ、夏希 💕'; // ← 設定のない日に表示されるデフォルト
```

## 管理者パネル（サイト内隠し機能）

メイン画面（index.html）の **フッターを5回タップ** すると管理者パネルが開きます。

| 操作 | 内容 |
|------|------|
| ➕ ガチャを1回追加 | 引き忘れたときや特別にもう1回引かせたいときに使う |
| 🗑 全履歴をリセット | 引いた記録を全消去、アルバムも全部 🔒 に戻る |
| 🔓 全写真を解放する | 誕生日に一気に全解放したいときに使う |
| 🎁 プレゼントテスト | PRESENT_SCHEDULE に登録したプレゼントを今すぐ確認できる |
| 🔄 プレゼント開封記録リセット | 同じ日にもう一度プレゼントを出したいときに使う |

## ゲームのデバッグモード（game.html）

ゲームオーバー画面で以下のいずれかを操作するとデバッグメニューが開きます。

| 操作 | 内容 |
|------|------|
| キーボード | `d` → `e` → `b` → `u` → `g` と順番に入力 |
| スマホ | スコア表示を **5回タップ**（画面に `・` が増えていく） |

デバッグメニューでできること：

| ボタン | 内容 |
|--------|------|
| 🎉 クリア画面を表示 | プレゼントボックス演出を確認できる |
| 🎁 プレゼント画面を表示 | ゲームプレゼントの内容画面を確認できる |
| 🗑 ベストスコアをリセット | ベストスコアを0に戻す |

## データの保存について

このサイトはサーバーを使わず、**スマホのブラウザ（localStorage）** にデータを保存します。

| 保存されるデータ | 内容 |
|-----------------|------|
| 引いた写真の記録 | アルバムの解放状況 |
| 今日引いたかどうか | 1日1回制限の管理 |
| コメント | 各写真に入力したひとことメモ |
| 開封済みプレゼント | プレゼントボックスセクションの内容 |
| ゲームのベストスコア | ハートフラッピーの記録 |

> **注意**: 異なる端末・異なるブラウザ間での同期はされません。夏希のスマホの同じブラウザで使い続けてください。
